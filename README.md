# Privacy Policy – AutoTabClicker

**Last updated:** October 20, 2026

AutoTabClicker is a browser extension that automates mouse clicks, keyboard input, action sequences, and scrolling within user-selected browser tabs.

### 1. Data Collection

AutoTabClicker does not collect or transmit personal information to the developer's servers. The extension does not require account registration and does not include advertising or analytics tracking.

### 2. Browser Access

To provide its automation features, AutoTabClicker accesses information about user-selected browser tabs, including tab identifiers, titles, URLs, cursor positions, and selected webpage elements.

This information is processed locally to identify automation targets and execute user-configured actions.

### 3. Local Storage

AutoTabClicker stores user preferences locally in the browser, including:

- Automation settings and intervals
- Saved action sequences and scrolling presets
- Keyboard configurations
- Theme and interface preferences
- Custom shortcut settings

These settings are not transmitted to external servers operated by AutoTabClicker.

### 4. Data Sharing

AutoTabClicker does not sell or share user data with advertisers or third-party analytics providers.

The optional "Rate us" feature may open the Microsoft Edge Add-ons listing, where Microsoft's own privacy terms apply.

### 5. User Control

Users can change or delete saved settings within the extension. The Hard Reset feature clears stored extension settings and stops active automation sessions. Uninstalling the extension also removes its locally stored extension data, subject to browser behavior.

### 6. Remote Code

AutoTabClicker does not download or execute remotely hosted extension scripts. Its JavaScript files are included in the installed extension package.

### 7. Changes to This Policy

This policy may be updated if AutoTabClicker introduces new features or changes its data handling practices.
