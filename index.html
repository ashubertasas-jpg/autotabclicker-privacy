Privacy Policy

Last updated: October 20, 2026

AutoTabClicker is a browser extension that automates mouse clicks, keyboard input, action sequences, and scrolling in user-selected browser tabs. We designed the extension to process automation settings locally, without requiring user accounts.

1. Information we process

To provide its functions, AutoTabClicker accesses information about tabs chosen for automation, including tab identifiers, tab titles, URLs, cursor positions, and selected page elements. This information is processed locally to identify the appropriate targets and perform actions the user configures.

The current extension version does not contain developer-operated analytics, account registration, or telemetry that sends this information to AutoTabClicker servers.

2. Information stored on your device

The extension saves settings in browser extension storage. These may include:

  • Mouse click and keyboard automation settings, timing, and repeat counts.
  • Saved action sequences, profiles, and Auto Scroll presets.
  • Preferred light/dark theme, layout preferences, and keyboard shortcut settings.
  • Temporary session information needed to distinguish automated browser tabs.

These settings are used to provide the extension's functionality and are not sent to AutoTabClicker-operated servers.

3. Browser permissions

AutoTabClicker uses activeTab, debugger, scripting, storage, and tabs permissions to interact with selected tabs, send simulated input, track cursor position when requested, and retain configuration. The debugger connection is used to run automation and is released when a task stops.

4. Sharing and third parties

AutoTabClicker does not sell user information and does not share automation settings or browsing data with advertisers or analytics providers. Opening the optional "Rate us" link takes you to a browser add-on store subject to that store's privacy terms.

5. Your controls

You can edit or remove saved settings inside the extension. The Hard Reset action clears locally saved extension preferences and profiles. Uninstalling the extension removes its own browser-managed storage according to browser behavior.

6. Remote code and security

The extension's scripts are included in its installation package. The current extension does not download or execute remotely hosted JavaScript or WebAssembly. Some websites, including browser games, may restrict simulated keyboard and mouse input.

7. Policy changes

This policy may be updated when features or data processing practices change. The updated version will be published here with a revised date.
